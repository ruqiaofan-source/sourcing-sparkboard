## BuckyDrop Agent Platform (buckyagent.ddaok.com)

### Customer Side
- Dashboard: KPIs (Sourcing Requests, Active, Confirmed, Total Orders, Total Spent), Recent Orders, Quick Actions
- Order Status
- Sourcing Requests (status filter cards)
- New Request form
- Profile
- Address Management
- Settings
- Help & Support

### Admin Side
- Dashboard: KPIs (Total Users, Active Agents, Sourcing Requests, Pending, Completed, Total Orders, Revenue, Total Agents), Recent Activity
- User Management
- Agent Management (agent cards with avatar, rating, experience, specialty, status)
- Agent Applications
- Sourcing Requests (searchable table, User/Agent filter dropdowns)
- Order Management (BuckyDrop status column, Customer/Agent filters)
- QA Management (FAQ CRUD)
- Testimonials
- Articles (insights/blog management)
- Analytics (Revenue, Users, Agents, Orders, Uptime, Response, Satisfaction, Growth charts, Top Agents)
- Settings
